# Sicurezza

## Confini

- Il server deve rimanere in ascolto su `127.0.0.1`.
- Non committare database, documenti, visure, screenshot, esportazioni, `.env`, token o credenziali.
- L'autenticazione a servizi esterni resta manuale.
- I caricamenti accettano solo PDF, JPG, JPEG e PNG entro il limite configurato.
- I nomi dei file salvati sono generati dall'applicazione e non derivano direttamente dal percorso fornito dal browser.

## Segnalazioni

Interrompere l'uso e conservare il log diagnostico privo di dati personali. Non allegare documenti reali a issue GitHub.
