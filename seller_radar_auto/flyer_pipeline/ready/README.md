# Grafiche pronte

Le grafiche finali vanno caricate in sottocartelle giornaliere:

`ready/YYYY-MM-DD/`

Formati accettati per il download mattutino:
- PDF A6 verticale pronto stampa;
- PNG/JPG anteprima.

Nome file consigliato:
`F1_SellerSignal_[Comune]_[Via]_[TipoSegnale]_[YYYY-MM-DD].pdf`

La pagina `../downloads.html` legge automaticamente questa cartella e mostra i pulsanti DOWNLOAD per i file del giorno selezionato.
