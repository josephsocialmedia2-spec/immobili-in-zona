# F1 Immobiliare — immobili-in-zona

Repository ricostruito per F1 Seller Radar.

## Obiettivo
Censire e classificare opportunità immobiliari nel territorio operativo, preservando sempre il master e distinguendo:
- fermate pronte;
- indirizzi da verificare;
- backlog;
- storico non attivo.

## Territory discovery
La discovery supporta Comuni, frazioni, borgate e località.

Centro recovery: **Sant'Ambrogio di Torino**  
Raggio operativo recovery: **20 km**

## Regola dati
I dati storici originali non vengono inventati. Eventuali backup di `work_queue.csv`, master, snapshot mercato, catasto o pratiche edilizie vanno reinseriti nei file dati reali.
